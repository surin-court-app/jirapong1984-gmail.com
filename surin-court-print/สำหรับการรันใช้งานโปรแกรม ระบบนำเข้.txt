สำหรับการรันใช้งานโปรแกรม ระบบนำเข้าเอกสารบัญชีหมาย (สุรินทร์ คอร์ท) คุณสามารถเปิดใช้งานผ่าน Terminal ใน VS Code หรือ Command Prompt ได้ด้วยคำสั่งตามลำดับดังนี้ครับ:

คำสั่งสั่งรันโปรแกรม (Development Mode)

Bash
npm run dev
(เมื่อรันแล้ว ให้คลิกลิงก์ http://localhost:5173/ หรือสลับไปที่เบราว์เซอร์เพื่อเริ่มใช้งาน)

หากต้องการหยุดการรันโปรแกรม

กด Ctrl + C บนคีย์บอร์ดที่หน้าต่าง Terminal

พิมพ์ y แล้วกด Enter

กรณีเพิ่งย้ายเครื่อง หรือรันคำสั่งแรกแล้วขึ้น Error หาโมดูลไม่เจอ
ให้ติดตั้งไลบรารีที่จำเป็นก่อนด้วยคำสั่ง:

Bash
npm install
แล้วค่อยสั่ง npm run dev อีกครั้งครับ
